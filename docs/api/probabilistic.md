# probabilistic

Probabilistic fatigue assessment — Monte Carlo, sensitivity, reliability.

- `monte_carlo` — Latin Hypercube Sampling driver, the `RandomVariable` specification, and the `MonteCarloEngine`.
- `distributions` — ready-made `RandomVariable` collections for material-property scatter, geometric tolerance, and corrosion.
- `sensitivity` — Sobol variance-based global sensitivity indices plus FORM (First-Order Reliability Method) for reliability-index / β computation.

::: feaweld.probabilistic
